# Don't Trash the Power. Recycle It Right. — Website

A responsive, static, multi-page campaign website.

## Pages
- Home
- Battery Safety
- What to Recycle
- Proposed Battery Drive Day
- Find a Drop-off
- Get Involved
- Contact

## Preview
Open `index.html` in a browser. Keep the `assets` folder beside the HTML files.

## Publish
Upload the complete folder contents to any static web host (for example Netlify, GitHub Pages, or a standard web host). No build step is required.

## Before public launch
1. Confirm campaign owner, contact details, and legal/organizational identity.
2. Obtain written approval before using any retailer name or logo in a way that implies partnership. The current copy explicitly labels the Home Depot event as proposed and not confirmed.
3. Confirm local battery rules and have an authorized recycler approve the exact accepted-material list.
4. Connect the Contact form to a form provider or backend. It is currently a non-transmitting demo.
5. Add a real campaign QR code only after choosing the final live website URL.
6. Review all safety and acceptance details with local authorities and the receiving recycler.
